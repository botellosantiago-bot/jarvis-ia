# Capturas para el README

Toma estas capturas con datos de ejemplo (nada de clientes, correos ni citas reales) y guárdalas aquí con estos nombres:

| Archivo | Qué mostrar |
|---|---|
| `hub.png` | El hub en escritorio con un día lleno: horario, citas y pendientes. |
| `movil.png` | El hub en el celular (390 px de ancho). |
| `telegram.png` | Una conversación: "comida con Ana el viernes 2pm" y la respuesta de Jarvis. |
| `briefing.png` | El resumen de la mañana en Telegram, con sus botones. |

Después cambia en el README cada "📸 Captura pendiente" por la imagen, por ejemplo `![El hub](docs/capturas/hub.png)`.
